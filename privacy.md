# Privacy Policy for Vagudle Bot

**Last Updated:** August 17, 2026

Thank you for using **Vagudle Bot**. This Privacy Policy explains what information is collected when the Bot interacts with you, how it is used, and your rights regarding that data.

By interacting with Vagudle Bot, you agree to the practices described in this policy.

---

## 1. Data We Collect & How We Use It

### Commands & Interactions
Vagudle Bot provides slash commands for playing Vagudle through Discord, including challenges, duels, the daily word, and leaderboards. When you use a command, the Bot processes:

* **Discord User ID:** Used to identify you for gameplay, leaderboard entries, and DM delivery.
* **Discord Username/Display Name:** May be shown in embeds (e.g. leaderboard entries, duel results).
* **Command Input:** Any options you provide (word length, difficulty, opponent selection, etc.) are used only to run the requested command.

### Game & Leaderboard Data
To support duels, the daily word, and leaderboards, Vagudle Bot stores the following in Cloudflare KV and Cloudflare D1:

* Discord User ID
* Duel and daily results (word, guesses used, win/loss, completion time)
* Leaderboard records (matches played, matches won, opponents faced)
* Group streak data for servers/DM groups participating in the daily word
* Configured daily-word channel per server

This data is retained to support ongoing gameplay features (leaderboards, streaks) and is not used for analytics, advertising, or profiling outside of the game itself.

### Temporary Activity Data
When a Vagudle Activity duel is launched, a short-lived payload containing the following fields is stored in Cloudflare KV:

* Discord User ID
* Duel identifier
* Word, word length, dictionary type, and guess limit
* Timestamp of creation

This data exists solely to load the duel inside the Discord Activity and is **automatically deleted after 24 hours** with no manual intervention required.

### Direct Messages
Vagudle Bot sends Direct Messages directly to Discord users for game-related notifications, such as duel results and duel expiry notices. The content of these messages (results, word, guess counts) is generated by the Bot itself based on the game data above and is not independently stored beyond what's described in this policy.

### Temporary Logs
To maintain performance and debug errors, the Bot utilizes temporary operational logging:

* Basic request metadata (User IDs, command usage, delivery status) may be transiently logged to assist with debugging.
* **Retention:** These logs are transient and are automatically rotated out. They are not used to build long-term user profiles beyond the persistent game data described above.

---

## 2. Infrastructure & Data Security

* **Network Infrastructure:** Vagudle Bot receives webhook traffic from the Vagudle web app (vagudle.king-tajin.dev) through a **Cloudflare Tunnel**, authenticated with a shared secret header to ensure only the Vagudle web app can trigger the Bot.
* **Persistent Data Storage:** Duel results, leaderboard records, and group streak data are stored in **Cloudflare D1**. Daily-word progress, activity duel payloads, and channel configuration are stored in **Cloudflare KV**.
* **Log Storage:** All temporary operational logs are stored securely on a dedicated, private server managed directly by the developer.
* **Data Sharing:** We **never** sell, trade, or share any user data or message content with third-party advertisers or external entities. Cloudflare is used solely as infrastructure and is subject to [Cloudflare's Privacy Policy](https://www.cloudflare.com/privacypolicy/).

---

## 3. Data Deletion & User Rights

You have the right to request deletion of any data associated with you.

* **Temporary Logs:** To request immediate purging of any transient logs associated with your Discord User ID, please email **developer@king-tajin.dev**.
* **Activity Duel Data:** Temporary KV data expires automatically after 24 hours. If you need it removed sooner, email **developer@king-tajin.dev** with your Discord User ID and approximate time of the session.
* **Duel Results & Leaderboard Data:** To request deletion or correction of persistent leaderboard/duel/streak data associated with your Discord User ID, email **developer@king-tajin.dev**.
* **Processing:** All deletion requests are processed promptly.
